# Scripts do esquema

Coloque aqui os arquivos SQL do modelo de dados, em ordem numérica:

```text
010_tables.sql
020_indexes.sql
030_sequences.sql
040_packages.sql
050_seed_data.sql
```

Eles são executados como o usuário definido por `DB_SCHEMA_USER` durante a
primeira criação do volume. O SQL*Plus disponibiliza estas variáveis:

```sql
&&DATA_TABLESPACE
&&INDEX_TABLESPACE
```

Exemplo:

```sql
CREATE TABLE exemplo (
  id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  descricao VARCHAR2(200) NOT NULL
) TABLESPACE &&DATA_TABLESPACE;

CREATE INDEX ix_exemplo_descricao
  ON exemplo (descricao)
  TABLESPACE &&INDEX_TABLESPACE;
```

Para aplicar os arquivos depois que o banco já foi criado:

```bash
make apply-schema
```

Os scripts devem ser idempotentes caso sejam executados mais de uma vez.
